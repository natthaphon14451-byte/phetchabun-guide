# Phetchabun Travel & Stay Official Guide (Bilingual TH / EN)

เว็บไซต์แนะนำการท่องเที่ยวและรวบรวมที่พัก จ.เพชรบูรณ์ สไตล์ **Amazing Thailand (Tourism Authority of Thailand - TAT)** พร้อมระบบสลับ 2 ภาษา (ไทย-อังกฤษ) และการเชื่อมต่อกับ **LINE Official Account (LINE OA)**

---

## 🌟 ฟีเจอร์ใหม่ระดับ International
1. **Bilingual 2 ภาษา (TH / EN):**
   - มีปุ่มสลับภาษา `[ TH | EN ]` ที่มุมขวาบน
   - สลับเนื้อหาทั้งหมด (หัวข้อ, คำบรรยาย, ข้อมูลที่พัก, ที่อยู่, ปุ่มกด) ได้ทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่
   - จดจำภาษาที่ผู้ใช้เลือกล่าสุดผ่าน `localStorage`

2. **ดีไซน์ระดับสากล (Inspiration จากเว็บ ททท. Tourism Thailand):**
   - Typography พรีเมียม: ใช้ฟอนต์ *Plus Jakarta Sans*, *Prompt* และ *Playfair Display*
   - การจัดวางแบบ Editorial Magazine: แถบ Quick Fact Stats (ความสูง 1,768m, อุณหภูมิเฉลี่ย 18-25°C, มรดกโลก UNESCO, ระยะทางจาก กทม.)
   - การ์ดท่องเที่ยวและที่พักแบบ Modern Luxury สไตล์ Amazing Thailand

3. **ระบบติดต่อที่พักตรง (Direct Contacts):**
   - 📞 เบอร์โทรศัพท์ตรง (คลิกโทรออกได้ทันที)
   - 💬 LINE ID ของที่พัก
   - 📍 พิกัดที่อยู่ตามจริง
   - 🗺️ ปุ่มเปิด Google Maps นำทาง
   - 💬 ปุ่มทักแชทบอท LINE OA

4. **การเชื่อมต่อ LINE OA:**
   - ปุ่ม Floating LINE Chat ลอยขวาล่าง พร้อม Tooltip 2 ภาษา
   - Deep Links ส่งข้อความระบุชื่อสถานที่/ที่พักเข้า LINE OA โดยอัตโนมัติ
